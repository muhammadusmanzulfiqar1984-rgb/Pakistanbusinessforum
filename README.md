# Pakistan Business Forum – Strategic Policy & Research Function

A professional website for Pakistan Business Forum and its Strategic Policy & Research Function.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

- **Home** - Overview of the organization and services
- **About Us** - Mission, values, team, and approach
- **Practice Areas** - Detailed information about service areas
- **Research & Insights** - Research approach, themes, and publications
- **Media & Communications** - Communication services and strategies
- **Measurement & Impact** - Evaluation and impact assessment services
- **Contact** - Contact information and inquiry form

## Design

- Warm off-white background (#F6F2EF) with section contrast (#EEEAE6)
- Deep institutional maroon (#7A1F2B) and soft line accents (#9B5A63)
- Professional typography with generous spacing
- Responsive layout for all screen sizes

## Build

To create a production build:

```bash
npm run build
npm start
```
